# THUMBLY PRO — K-POP Thumbnail Studio

K-POP音楽番組系YouTubeサムネイルをブラウザだけで制作するGitHub Pages向けの静的サイトです。

## 主な機能

- 10種類の参考テンプレート
- テンプレート別の文字位置・サイズ・フォントプリセット
- Google Fonts系フォントを約30種類搭載（韓国語・日本語・英数字）
- 写真のドラッグ＆ドロップ / 全体表示 / 全面表示
- 明るさ・コントラスト・彩度・ぼかし調整
- 文字のサイズ・太さ・字間・行間・回転・縦横比・透明度
- 影 / 縁取り / 発光 / 背景ボックス
- テーマカラー
- 図形・ライン・グラデーション・ドットフレーム追加
- レイヤー選択 / 前後移動 / 複製 / 削除
- 選択中だけ点線の選択枠を表示。空白クリックで解除
- グリッド / セーフエリア
- Undo / Redo
- PNG / JPG / WEBP
- 1× / 2× / 3× / 4× / 6×出力
- JPG/WEBPの品質調整
- 作成履歴（ブラウザのlocalStorage）

## フォントについて

Google Fonts CSS APIを利用してWebフォントを読み込みます。Google Fontsでは複数ファミリー、ウェイト、可変フォントをCSS APIから指定できます。

## 使い方

1. このフォルダをGitHubリポジトリへアップロード
2. GitHub Pagesを有効化
3. `index.html` を開く

外部フォントを使うため、初回表示時はインターネット接続が必要です。写真や履歴はブラウザ内で処理されます。
