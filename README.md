# THUMBLY STUDIO

K-POP音楽番組のYouTubeサムネイルを、テンプレート・レイヤー・タイポグラフィ・素材・エフェクトで制作するブラウザ型デザインエディターです。

## 主な機能
- 送付された10種類の参考サムネイルをテンプレート化
- Google Fonts系の韓国語・日本語・英数字フォントを多数搭載
- Photoshop / Canva風レイヤーパネル
- レイヤー表示・ロック・順序変更・複製・削除
- 複数レイヤー選択とグループ化
- 写真ドラッグ&ドロップ / 全体表示 / 全面表示
- 写真の明るさ・コントラスト・彩度・ぼかし
- テキストのフォント・サイズ・太さ・字間・色・縁取り・影・発光・背景・回転・拡縮・位置
- K-POP向けグラデーション / フレーム / ドット / Glow / Vignette / Scanlines / Noise
- テンプレート別のロゴ素材（参考画像から抽出した素材）
- ORIGINAL / EDIT / Before & After
- 自動レイアウト（FaceDetector対応ブラウザでは顔位置を利用）
- カラーパレット
- 保存したテキストスタイル
- バリエーション生成
- プロジェクト保存・再読み込み
- PNG / JPG / WEBP、1×〜6×、品質指定の書き出し
- 作成履歴をブラウザ内に保存

## GitHub Pages
このフォルダをリポジトリにアップロードし、GitHub Pagesで `index.html` を公開してください。

Google Fontsはオンライン読み込みです。フォント表示にはインターネット接続が必要です。
