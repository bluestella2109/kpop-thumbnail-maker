# THUMBLY PRO
K-POP音楽番組風サムネイルをブラウザだけで制作するGitHub Pages向けサイトです。

## 追加した機能
- 10種類の番組風テンプレート
- テンプレートごとの文字サイズ・位置・フォントプリセット
- 写真ドラッグ&ドロップ / 全体表示 / 全面表示
- 「写真差し替え」と「元サムネ忠実表示」の切替
- テキスト直接ドラッグ
- Shiftで水平/垂直移動、矢印キーで1px移動
- グリッド / セーフエリア / 中央X・Y / スナップ
- フォント、サイズ、太さ、透明度、文字色、縁取り、影
- レイヤー選択、前面/背面、複製
- Undo / Redo
- PNG / 高画質PNG / JPG出力
- JSONプロジェクト保存・読み込み
- マイページの作成履歴（最大30件）
- レスポンシブUI

## GitHub Pages
ZIPを展開して、中身をGitHubリポジトリのルートへアップロードしてください。外部APIやFirebaseは不要です。
