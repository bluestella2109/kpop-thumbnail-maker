# THUMBLY — K-POP サムネイルメーカー

GitHub Pagesでそのまま公開できる、ブラウザ完結型のK-POP音楽番組風サムネイル作成サイトです。

## 主な機能
- 10種類の参考テンプレートから選択
- 写真のクリック選択 / ドラッグ＆ドロップ
- 番組名・グループ名・メインタイトル・サブタイトル編集
- 7色のテーマカラー + カスタムカラー
- キャンバス上の文字をドラッグして配置変更
- 720×404 PNG書き出し
- ブラウザのlocalStorageによる作成履歴
- スマホ / タブレット / PC対応
- 外部バックエンド不要

## GitHub Pages
このフォルダをGitHubリポジトリにアップロードし、Settings → Pages → Deploy from a branch を選択してください。
