# THUMBLY K-POP STUDIO V4

K-POP音楽番組風サムネイルを作るための、Canva / Photoshop風ブラウザエディターです。

## V4の主な変更

- テンプレート選択時に、番組名・グループ名・タイトル・サブタイトルの編集欄を自動生成
- 入力内容をキャンバスとレイヤーへ即時反映
- テンプレートごとに位置・サイズ・フォントをプリセット
- テンプレートごとのレイヤー構成を自動生成
- 「原稿プレビュー」レイヤーを追加。目のアイコンで元サムネを確認可能
- テキスト追加時に必ず中央付近へ生成し、最前面の選択状態で表示
- 日本語 / English / 한국어 のUI切り替え
- Google Fontsを多数搭載
- レイヤーの表示 / 非表示、ロック、並べ替え、複製、削除、グループ化
- 写真のドラッグ&ドロップ、フィット / フィル、補正
- PNG / JPG / WEBP、1〜6倍で書き出し
- マイプロジェクト、作成履歴、バリエーション、Before / After

## 使い方

1. `index.html` をブラウザで開く、またはGitHub Pagesへアップロード
2. 左の「テンプレート」からテンプレートを選択
3. 「番組名」「グループ名」「タイトル」「サブタイトル」を入力
4. 「写真」から画像を追加
5. レイヤーを選択して右側のプロパティで細かく調整
6. 「書き出す」から形式・倍率・品質を選択

## 注意

Google Fontsをオンライン読み込みしています。公開後の初回利用時にはインターネット接続が必要です。

ロゴ画像は今後追加できるように構造を分離しています。
